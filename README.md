# Alex von Jena's Data Analytics Portfolio
This portfolio is made up of multiple data analytics projects. Each containing completed Python code, data analysis, visualizations, and executive summaries that demonstrate the full data analytics process, from data cleaning and exploratory data analysis to statistical analysis, machine learning, and communicating actionable insights. Using tools such as Python, pandas, NumPy, Matplotlib, Seaborn, and scikit-learn, these projects demonstrate my technical proficiency, analytical problem solving abilities, and capacity to translate complex datasets into meaningful business recommendations. The goal of this portfolio is to demonstrate both my technical skills and my ability to communicate findings effectively to technical and non-technical stakeholders.
